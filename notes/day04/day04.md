### 链表删除类题目总结

#### 一、问题本质

> [!IMPORTANT]
>
> **单链表中，永远删除的是「当前节点的下一个节点」**

原因：

- 单链表无法直接访问前驱
- 删除操作必须通过修改前驱节点的 `next` 指针完成

#### 二、为什么一定要使用虚拟头结点（Dummy Node）

##### 不使用虚拟头的问题

- 删除头结点需要单独处理
- 删除中间节点是另一套逻辑
- 逻辑分裂，容易出错

##### 使用虚拟头的好处

- 把头结点统一成普通节点
- 所有的删除操作统一为：

```text
cur ->next = cur ->next ->next;
```

#### 三、链表删除的核心模型：双指针角色分离

| **指针**        | **是否移动** | **作用**    |
| --------------- | ------------ | ----------- |
| dummy（虚拟头） | ❌ 永远不动   | 稳定前驱    |
| cur（遍历指针） | ✅ 会移动     | 遍历 + 删除 |



#### 四、遍历与删除的正确模板

```C++
while (cur->next) {
    if (cur->next->val == val) {
        cur->next = cur->next->next; // 删除
    } else {
        cur = cur->next;             // 只有没删才前进
    }
}
```
